HardTopNet GitHub projects portal

This portal provides access to various GitHub projects maintained by HardTopNet. Explore the repositories to find tools, libraries, and resources for your development needs.

AI projects

BenchmarkPy

Description:
Simple command-line tool for benchmarking LLMs.
Supports Ollama and integrated transformers models.
Language: Python

copy-model-cli

Description:
Command-line tool for managing Ollama models.
Lists, copies, and deletes models. Copy uses manifests to detect relevant blobs.
Language: Python

Misc tools

WinOCR_cli

Description:
Command-line OCR tool for Windows that leverages the Windows internal OCR capabilities.
Supports multiple languages.
Language: Python

LogFileTrigger

Description:
Monitor log files and trigger actions based on log content.
Uses a simple pattern matching approach.
Language: C#/.NET

FileWatcherExec

Description:
Monitor file system changes and trigger actions based on file events.
Uses a simple pattern matching approach.
Language: C#/.NET

CertificateExpirationWatcher

Description:
Monitor SSL certificate expiration and send alerts by email.
Supports multiple domains, and allows multiple reminder intervals.
I designed this tool when Let's Encrypt stopped sending reminders to free accounts.
Language: C#/.NET, Docker
